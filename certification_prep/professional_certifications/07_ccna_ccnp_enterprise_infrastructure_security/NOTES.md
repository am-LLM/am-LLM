# Cisco Enterprise Routing & Switching (CCNA / CCNP Enterprise 350-401 ENCOR)

## 1. Border Gateway Protocol (BGP) Best Path Selection Algorithm

When a BGP router receives multiple routes to the same destination prefix, it resolves the preferred path via the following 10-step sequential evaluation hierarchy:

```
                       BGP BEST PATH DECISION FLOW
 ┌───────────────────────────┐
 │ 1. Highest WEIGHT (Cisco) │ (Default: 0, Local to router)
 └─────────────┬─────────────┘
               ▼
 ┌───────────────────────────┐
 │ 2. Highest LOCAL_PREF     │ (Default: 100, Sent across iBGP)
 └─────────────┬─────────────┘
               ▼
 ┌───────────────────────────┐
 │ 3. Locally Originated     │ (network / aggregate-address > redistribute)
 └─────────────┬─────────────┘
               ▼
 ┌───────────────────────────┐
 │ 4. Shortest AS_PATH       │ (Number of AS hops)
 └─────────────┬─────────────┘
               ▼
 ┌───────────────────────────┐
 │ 5. Lowest Origin Code     │ (IGP < EGP < Incomplete "?")
 └─────────────┬─────────────┘
               ▼
 ┌───────────────────────────┐
 │ 6. Lowest MED (Metric)    │ (Multi-Exit Discriminator sent between AS)
 └─────────────┬─────────────┘
               ▼
 ┌───────────────────────────┐
 │ 7. eBGP over iBGP         │ (External routes preferred over Internal)
 └─────────────┬─────────────┘
               ▼
 ┌───────────────────────────┐
 │ 8. Lowest IGP Metric to   │
 │    BGP Next-Hop           │
 └─────────────┬─────────────┘
               ▼
 ┌───────────────────────────┐
 │ 9. Oldest eBGP Route /    │
 │ 10. Lowest BGP Router ID  │
 └───────────────────────────┘
```

## 2. OSPFv3 & Multi-Area Enterprise Routing
* **LSA Types**:
  * Type 1: Router LSA (Intra-area).
  * Type 2: Network LSA (Designated Router on broadcast link).
  * Type 3: Summary LSA (Inter-area generated by ABR).
  * Type 4: ASBR Summary LSA (Route to ASBR generated by ABR).
  * Type 5: AS External LSA (Redistributed routes generated by ASBR).
  * Type 7: NSSA External LSA (Not-So-Stubby Area external).
